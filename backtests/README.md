# Backtest results

Store exported MT5 Strategy Tester reports and supporting notes in this folder.

Suggested naming convention: YYYY-MM-DD_EA-version_symbol_timeframe_period.ext

For each report, include the EA version, source commit, test period, timeframe, deposit, modelling method, and spread/commission assumptions. Compare drawdown, profit factor, win rate, and trade count—not only net profit.

Do not commit account credentials, investor passwords, account numbers, or other private information.
